# OSCP Cheat Sheet

A comprehensive collection of techniques, commands, and exploits for OSCP exam preparation.

## Structure

This repository uses GitHub Issues as a knowledge base for quick reference during practice and exam preparation.

### Categories

- **Enumeration** - Information gathering and reconnaissance
- **Exploitation** - Vulnerability exploitation techniques
- **Privilege Escalation** - Linux and Windows privilege escalation
- **Post-Exploitation** - Maintaining access and lateral movement
- **File Transfers** - Methods to transfer files between systems
- **Web Application** - Web-specific attacks and techniques
- **Active Directory** - AD enumeration and attacks
- **Buffer Overflow** - BOF exploitation techniques

## Usage

1. **Browse Issues** - Each technique is documented as an issue with the `cheatsheet-entry` label
2. **Filter by Category** - Use labels to filter by technique category
3. **Search** - Use GitHub's search to find specific commands or techniques
4. **Add New Entries** - Use the issue template to maintain consistent formatting

When adding new techniques:
1. Click "New Issue"

4. Add appropriate labels
5. Submit

## Preparation Tips

- Practice each technique in a lab environment
- Understand the theory behind each command
- Document your own variations and findings
- Keep track of what works in different scenarios
